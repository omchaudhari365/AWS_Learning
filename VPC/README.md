# AWS VPC

**Amazon VPC (Virtual Private Cloud)** is a networking service provided by AWS that allows you to create a **secure and isolated virtual network** for your AWS resources.

VPC gives you control over networking components such as **subnets, route tables, internet gateways, and security groups**.

## Key Features

* Isolated virtual network
* Public and private subnets
* Route tables
* Internet and NAT gateways
* Security groups and network ACLs
* Custom IP address ranges
