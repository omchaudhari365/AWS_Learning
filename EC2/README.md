# AWS EC2

**Amazon EC2 (Elastic Compute Cloud)** is a cloud computing service provided by AWS that allows users to create and run virtual servers in the cloud.

EC2 can be used to host websites, run applications, deploy software, and perform various computing tasks without managing physical hardware.

## Key Features

* Resizable virtual servers
* Multiple instance types
* Scalable computing resources
* Secure access using Security Groups
* Flexible storage with EBS
* Pay-as-you-use pricing
