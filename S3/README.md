# AWS S3

**Amazon S3 (Simple Storage Service)** is a cloud storage service provided by AWS. It is used to store and manage data such as files, images, videos, backups, and website files.

S3 provides **high durability, scalability, security, and easy access** to stored data. It can also be used to **host static websites** containing HTML, CSS, and JavaScript files.

## Key Features

* Object-based storage
* Highly durable and scalable
* Secure access control
* Versioning and lifecycle management
* Static website hosting
* Pay-as-you-use pricing
